# Lab 3.3 Reflection

1. One challenge I faced when refactoring my code to use Tailwind was learning how to replace custom CSS with utility classes directly in the HTML. At first, it was a little confusing to remember which Tailwind classes controlled spacing, colors, text size, and responsiveness. I also had to make sure the QR Code Component and Blog Preview Card still looked close to the original designs.

2. Tailwind simplified the styling process because I could use classes such as `p-4`, `text-center`, `bg-white`, `rounded-xl`, and responsive prefixes like `sm:` and `md:` without writing as much CSS. This made it easier to make changes quickly and keep the styling consistent.

3. I might choose custom CSS instead of Tailwind when I need very specific styling, animations, or a design that would require too many utility classes. Custom CSS may also be better for a small project where adding Tailwind is not necessary.
